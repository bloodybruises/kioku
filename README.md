# kioku

A beginner-friendly, Pinterest-style aesthetic photography archive.

## Included
- responsive masonry gallery
- search and category filters
- favorites saved in the browser
- full-screen photo viewer
- add-photo feature saved locally in the browser
- your uploaded starter photos

## Run
Open `index.html` in a browser.

## Put it online for $0
Upload the folder to a static host such as GitHub Pages. This version does not need a server.

## Next step for a real social app
A true Pinterest-like site would need a backend for shared uploads, accounts, profiles, comments, follows, cloud image storage, moderation, and a database. Those can be added later without throwing away this front end.
